차고지 설정 안내

1) garage.kml의 각 차고지는 Point Placemark로 등록합니다. Placemark 이름은 depot/index.json의 placemark와 일치시킵니다.
2) 운수사를 추가하려면 해당 Placemark의 설명(Description)에 다음 형식으로 적습니다.
   운수사: 북부운수, 대원 계열사, 메트로버스
   여러 회사를 쉼표로 구분할 수 있으며, 설정 파일의 operators 목록과 합쳐집니다.
3) depot/index.json의 routes에는 해당 차고지에서 선택할 수 있는 KML 파일명을 적습니다.
   모든 노선을 허용하려면 ["*"]를 사용합니다.
4) 현재는 2211번 양방향을 북부운수 면목동 차고지에, 2416번을 중랑차고지에 연결했습니다.
   실제 운수사별 배차 관계에 맞춰 routes를 수정할 수 있습니다.
5) 자유주행은 노선 파일 없이 선택한 차고지 위치에서 시작하는 별도 선택지입니다.
